实验三：SPI 主从通信
参考课件：软件SPI通信.pdf

一、主机（Keil，STM32F103C8T6）
  1. 新建 STM32F103 空工程，新增 SPI.c、SPI.h，新增 main.c；
  2. 不用片内 SPI 外设，用普通 GPIO 模拟 SPI 时序（软件 SPI）：
        SPI_CS   PC13
        SPI_SCK  PC14
        SPI_MOSI PC15
        SPI_MISO PA0
  3. 在 main.c 中根据 SPI 协议用 SPI 接口输出字符，每个字符 16 bit，字符自己定义；
  4. 通信参数：16 位一帧、MSB first、SCK 空闲为高、CS 低有效、SCK 约 200 kHz。

二、从机（Quartus，EPM240T100C5）
  1. 用 Verilog 编写 SPI 从机：
        · sck、cs 各打一拍，与原信号做位运算得到边沿脉冲；
        · 每个 SCK 边沿脉冲到来时，输入、输出移位寄存器同时工作；
        · 用 CS 上升沿锁存输入移位寄存器结果，并用 case 判断需要返回的内容；
  2. 响应表：
        收到 0x0000 -> 返回 0x0123     收到 0x0004 -> 返回 0x1234
        收到 0x0008 -> 返回 0x2345     收到 0x000A -> 返回 0x3456
        其它        -> 返回 0xABAB
     从机要等 CS 上升、16 位收齐才知道该回什么，所以响应固定晚一帧；
  3. 引脚：CS = IO61、SCK = IO57、MOSI = IO55、MISO = IO53；
  4. 综合、布局布线、下载到 CPLD（.pof，JTAG）。

三、仿真（ModelSim）
  1. 新建 ModelSim 工程，编写主机、从机模块；
  2. 建立顶层模块，完成主机与从机的连线；
  3. 传输内容自加 1，连续跑 12 帧；
  4. 根据波形说明系统已正常工作、从机能正确响应主机命令。
